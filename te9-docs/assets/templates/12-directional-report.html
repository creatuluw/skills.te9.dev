The direction

Finish the remaining templates in similarity clusters, each through its browser gate, until v1.0.0 closes the full launch taxonomy.

The whole direction in one breath — the sections below are its position, its markers, its refusals and its tripwires. It sits on the page itself: no panel, no fence.

Because 01

Similarity clusters teach forward. Types built adjacently share grammar, so every cluster's review gate hardens conventions the next cluster inherits — the reporting cluster's panels become the plans cluster's starting point. Building one-by-one across the taxonomy would make every template learn alone.

Because 02

The gate stays per template. Browser approval after each build is where an instance teaches its Template: feedback given in the browser is folded in while the session is open, and each Document passes its own gate — never a batch verdict at the end of a cluster.

Because 03

html-docs stays vendored untouched until v1.0.0. The clean-room sibling's baseline must not move while the suite is still proving it stands on its own. Its deprecation is decided after the taxonomy is complete — never during, never by drift.

What v1.0.0 does not change
Done is a version, not a redesign

Reaching v1.0.0 changes the suite's size, not its law. Clay discipline, the script whitelist, self-describing placeholders, the review gate and the storage menu carry past it unchanged — the destination is the taxonomy complete, not a new suite.

Not the direction

Four refusals, stated in advance

A direction is defined as much by what it declines. These four are decided now, so no session has to re-litigate them under deadline.

Not the direction

Runtime interactivity beyond the whitelist

Clay discipline is zero scripts by default — <details> folds, :target jumps and hover states do the disclosing. The deck's canonical navigation and the figure's fullscreen listener are the only exemptions. A directional report is a document, not an app; anything more needs the whitelist.

Not the direction

Pixel-positioned hand figures

Figures are rendered, never drawn: Mermaid → pele → clayify → inline SVG, with the sources in assets/figures/ as the figure. A hand-positioned figure exists only where pele is genuinely impossible — an exception to argue, never a habit to keep.

Not the direction

Template breadth beyond the 35 before v1.0.0

The launch taxonomy is the suite's promise, and finishing it is the direction. A type outside the 35 waits until after v1.0.0 — then the extension protocol hears it on merit. Breadth now spends the runway the remaining clusters need.

Not the direction

pi-plugin-only features in the plain-dir core

te9-docs is a plain-dir Agent Skill first — agentskills.io conformant — packaged for pi as a thin plugin wrapper. The core stays client-agnostic: anything only pi could use lives in the wrapper, never in the plain-dir core.

The four refusals, one test: if a proposal makes the suite more app-like, more hand-drawn, broader than 35, or less portable — it is not the direction.

What reopening means — and what it does not
One question, not the whole bearing

A trigger reopens exactly one question, argued on its own evidence. It does not put the destination back up for debate: until a trigger fires, the remaining clusters, the gate discipline and the v1.0.0 marker all hold as written.
