Method · how these numbers were counted
Counted from the repository, not from memory — 2026-10-29

File counts and byte sums are ls -l listings summed per area (byte totals equivalent to du): 13 registered template files, 45 figure files, 34 example showcases, 5 build scripts. Registry: index.json parsed as JSON — 13 template entries, each mapped to its build cluster for Fig · 01. Changelog: CHANGELOG.md read as the version history for Fig · 02 — every suite file carries the same collection date. Self-exclusion rule: this document is the measuring instrument, so template counts and byte sums exclude it (13 files, not 14); the figure corpus includes this report's own two sources and two renders. Cluster mapping: founding trio = brief, dossier, deck; explainers = introduction of concepts, concept breakdown, top-down explainer, I-am-12 explainer, feature breakdown, what/how/why/who/when; analysis & reporting = decisions log, research report, directional report, management report.

Method · what each row counts, file by file
The register, auditable row by row

Templates (13 files, 511,616 B): every registered template from 01-brief to 13-management-report; the 14th file on disk is this report, excluded by the self-exclusion rule. Average registered template: 39,355 B ≈ 38.4 KB. Figures (45 files, 85,787 B): per-figure Mermaid sources (.mmd), clayify spec files, rendered SVGs and emitted legend fragments. Examples (34 files, 477,973 B): the pele reference gallery — one Clay showcase per diagram type plus the gallery index and the all-types compendium. Scripts (5 files, 28,581 B): render-figure.mjs, clayify.mjs, render-figure-video.mjs, the experiment builder and package.json — dependencies (node_modules) are not counted.

Observations

Four observations, one sentence each

What the numbers above say when read together — each observation a single sentence, each grounded in a figure stated on this page.

Observation O·01

Explainers is the largest build cluster — 6 of 13 registered templates (46%) — so the suite's center of gravity sits squarely on teaching documents.

Observation O·02

Registered templates average 38.4 KB (511,616 B ÷ 13), and the heaviest single file is the management report at 52.3 KB — reports carry their figures inline.

Observation O·03

Build progress compounds fastest in the 0.6.0 → 0.8.0 step (+3 templates, +50%), and the corpus has grown more than fourfold since founding (3 → 13).

Observation O·04

The pele reference gallery weighs 466.8 KB across 34 showcases — 0.93× the registered template corpus — making the suite's examples nearly as heavy as its products.
