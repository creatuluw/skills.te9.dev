# Dashboard design: start with the question

A while ago I stumbled upon a dashboard that had 47 charts. Forty-seven! The
funny thing was, nobody could tell me what question it answered.

So what should you do? I think you will find this quite simple: start with
the question, not with the charts.

## Step 1: write down the question

Grab a post-it and write the question your dashboard should answer. One
question, one post-it. If you need more questions, you need more dashboards.

1. Write the question down
2. Show it to one of your users
3. Ask them what they would click first

If they point at your 47 charts, you have some work to do ;-)
