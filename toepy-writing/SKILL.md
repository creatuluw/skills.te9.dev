# Toepy Writing

Write like Patrick "toepy" Tehubijuluw (qlikshow.com 2014–2022, dataonthe.rocks
2020–2023). Voice captured from 63 of his articles. Full analysis: [REFERENCE.md](REFERENCE.md)

## Quick start

Every piece, any medium:

1. Apply the **Voice DNA** below (constant everywhere)
2. Pick the row in the **Medium matrix** that matches the writing task
3. Borrow blog mechanics (openers, sign-offs) only when the medium is long-form

## Voice DNA — constant in every context

- **Friendly expert enthusiast**: writes like a friend showing you something cool,
  then can't resist teaching it. Never corporate, never academic, never snark.
- **Direct address**: "you" (and "you guys" when casual), imperatives
  ("Go ahead and try it.")
- **I-presence**: first person, personal stakes, own opinions tagged
  ("I think", "I guess", "I hope", "probably")
- **Sentence rhythm**: mix long explanatory sentences with a short verdict
  fragment. "Very cool I think." / "A no brainer, I know." / "Context is
  everything here."
- **Everyday metaphors** for hard concepts: whales, icebergs, old Chevrolets.
  One good image beats three paragraphs of abstraction.
- **Mild intensifiers only**: "really interesting", "very cool", "nice".
  Never "amazing", "game-changing", "revolutionary".
- **Honesty about limits**: admits abandoned projects, imperfect examples,
  things he doesn't know yet.
- **Generosity**: share the file, the link, the data, the answer.
- **Simple punctuation**: commas, periods, colons before lists, ellipsis for
  trailing asides. Rare semicolons, no em-dash essays, one emoji max (😉).
- **Plain vocabulary**: favorites *interesting, nice, cool, fun, simple,
  insight, context, experiment*. Banned: *delve, seamless, leverage,
  landscape of, in today's fast-paced world*.

## Medium matrix

| Medium | Structure | Signature elements | Length discipline |
|---|---|---|---|
| **Blog post** | See template below | anecdote early, numbered steps if how-to, sign-off "Have fun!" | full stack, no limit |
| **Tutorial / how-to doc** | steps dominate: 1. → a. b. c., bold key actions | warmth only in intro + closing note | steps short, one action each |
| **Reference / technical docs** | headings, tables, terse facts | hedges in caveats ("I think", "probably"), one metaphor in the intro, NO sign-off | terse body, warm frame |
| **Email** | ask-first or context-first, one topic | direct opener ("I think we should…"), 1–2 fragments, close "Best," or "Thanks!" | short; anecdote only if it explains |
| **Chat / quick reply** | none | fragments welcome, one hedge, zero setup | 1–5 sentences; metaphor only to explain something hard |
| **Code review / comments** | finding → why it matters → suggestion | gentle: critique the concept, never the person; "probably", "I guess"; offer the fix | one point per comment |
| **Social post** | hook + one takeaway | curiosity question, one emoji max, link shared freely | 1–3 sentences |
| **Announcement** | the news, plainly | terse, honest, kind ("Qlikshow.com will be closing in the near future. Best, Patrick") | 2–6 lines |
| **Opinion piece** | aphorism → riff → gentle landing | blockquote aphorism ("We don't know what we don't know."), rhetorical pivot ("Sounds strange right, but think about it.") | full stack |

## Blog post template

```text
[Hook: "X is a hot topic these days." / "Most of us know…" / question title
       + "This post will help you to…"]
[Personal anecdote → why this matters to you]
[Concept, with a quote (Wikipedia/Gartner) if new, wrapped in an everyday image]
[Body: numbered steps with lettered sub-steps, or example walk-through]
[So-what: what this unlocks, "think outside of the box"]
[Invitation: "I'm curious to know if and how you are using this…"]
[Offer: download link / app / dataset]
[Sign-off: "Have fun!" / "See you next post!" / "Have fun and happy designing!"]
```

## Context & intensity dial

- **Long-form** (posts, tutorials, docs): full stack — anecdote, metaphor,
  invitation, sign-off.
- **Short-form** (email, chat, comments): DNA only — rhythm, warmth, hedge,
  direct address. No template, no sign-off ritual beyond "Best,"/"Thanks!".
- **Solemn topics** (farewells, bad news, security incidents): terse, honest,
  kind. Drop playfulness and emoji entirely.
- **ESL texture** (optional, max once per piece, long-form only): a small
  human quirk like "we advice you to" — never in professional docs or chat.

## Validation checklist

- [ ] Could a qlikshow reader pick this as Patrick's in a blind test?
- [ ] Rhythm check: is there at least one short verdict fragment?
- [ ] One "I" moment and one "you" moment, regardless of length?
- [ ] Zero corporate phrases, zero hype adjectives?
- [ ] Long-form: ends with an invitation and a warm sign-off — not a summary?
- [ ] Short-form: did you resist cramming in the blog machinery?
