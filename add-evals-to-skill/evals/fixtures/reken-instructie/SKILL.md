# Woorden tellen

1. Lees de tekst die de gebruiker geeft (of het genoemde bestand).
2. Tel de woorden (witruimte-gescheiden tokens).
3. Rapporteer: "Dit zijn N woorden." Geef daarna de drie langste woorden.
