Hex Terrain Tile System — v3 Adaptive

Every feature is decided by neighbour affinity. Each terrain family rates roads, rivers, forest, rock, reeds, snow, sand (0–1). Road-prone cultures (desert, plains) seed roads that continue at full width through receptive neighbours and fade away where affinity drops. Rivers spring in valleys, pool as deltas in lakes, get absorbed by marsh — and leap height steps as waterfalls. Ornaments bleed across borders the same way: forests spill onto plains, sand onto hills, snow onto the volcano's flank. The board arrangement itself was picked to maximise neighbour compatibility.
